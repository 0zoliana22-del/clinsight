## 3. 失败分析

- **INT-004（test）** 漏掉：危重病人分诊、留观病情监测
- **INT-005（test）** 漏掉：按体重算剂量、夜间巡视
- **INT-006（test）** 漏掉：手术排期冲突、耗材备货、术后随访康复

### 已定位的系统性失败模式

1. **隐喻与口语没被识别**：急诊「从一百个里把这几个人挑出来」= 分诊，但词表里没有「挑」，规则版直接漏掉。
2. **一句话里两个痛点只取一个**：「抢救记录事后补 + 时间点靠估」同时是效率和准确性，聚类强制二选一。
3. **流程协调类没有对应类别**：骨科「排期撞车」属于跨部门协调，既不是效率也不是信息，规则版几乎全漏。
4. **领域名词不在表里**：「危急值」「耗材」「手术排期」都是标准临床术语，但词表是按通用中文写的。

这四条就是 v0.2 换 LLM 抽取的直接理由，也是评测集存在的意义：
**没有这组数字，换模型就是拍脑袋；有了这组数字，换完能证明好多少。**
